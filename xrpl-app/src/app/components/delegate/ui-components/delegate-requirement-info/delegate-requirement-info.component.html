DelegateSet grants another XRPL account only the transaction permissions you select. The delegate never receives your account's signing keys, and can perform only the granted actions.

Granting permissions

  • Select the delegate account and one or more permissions (up to 10).
  • Changes take effect when the DelegateSet transaction is validated.
  • Each delegate object uses owner reserve while it remains on the ledger.

Removing a delegate

  • Select an active delegation to remove all of its permissions.
  • Revocation does not reverse transactions the delegate already submitted.
  • Only the delegating account can create or remove its delegate objects.

Grant permissions only to accounts you trust. Delegated permissions are visible on the ledger and remain active until changed or removed.
