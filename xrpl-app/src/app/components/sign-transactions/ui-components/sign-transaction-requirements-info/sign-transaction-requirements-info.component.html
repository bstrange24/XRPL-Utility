Important Notes

  • All signing happens client-side — your secret/seed never leaves your device.
  • Transaction JSON must be valid XRPL format. You can edit it directly in the preview area.
  • Supports single key, regular key, and multi-sign (if SignerList is configured).
  • Use Get Transaction JSON to generate a base template for the selected type.
  • Signed Transaction produces a signed hex blob ready for submission.
  • Copy / download buttons let you save JSON or signed blobs for offline use or sharing.
Security & Risks
  • Never paste real secrets into untrusted tools.
  • Invalid JSON causes submission failure and burns the transaction fee.
  • Always test full flows on Devnet or Testnet first.
  • Double-check fields before submitting on mainnet — transactions are irreversible.
