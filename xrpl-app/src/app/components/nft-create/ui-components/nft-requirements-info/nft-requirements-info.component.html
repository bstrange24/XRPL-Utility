XRPL NFTs (Non-Fungible Tokens)

Create, burn, or modify metadata for NFTs using NFTokenMint, NFTokenBurn, and related transactions. NFTs support unique digital collectibles, art, tickets, credentials, and more.

Key Requirements

Mint NFT
URI Required (hex, max 256 bytes)
Taxon Required
TransferFee Optional (0–50%)
Flags Optional
Modify Burn
NFTokenID Required
Owner (for burn) Current holder or issuer (if burnable)

Important Notes

  • Requires the NonFungibleTokensV1_1 (or later) amendment.
  • Each minted NFT consumes owner reserve (~0.2 XRP) until burned.
  • URI must be hex-encoded (usually IPFS/Arweave link). Max 256 bytes.
  • Taxon is for grouping (no uniqueness enforced).
  • Common flags: tfBurnable, tfMutable, tfTransferable, tfOnlyXRP.
Irreversibility & Flag Considerations
  • Most flags and metadata are permanent after minting.
  • If tfMutable is not set, the URI cannot be changed later.
  • Burning is permanent — the NFT ID is destroyed forever.
  • Always test on Devnet/Testnet first.
