XRPL NFTs (Non-Fungible Tokens)

Create, burn, or modify metadata for NFTs using NFTokenMint, NFTokenBurn, and related transactions. NFTs support unique digital collectibles, art, tickets, credentials, and more with flags for burnability, transferability, mutability, and transfer fees.

🎨 Mint NFT NFTokenMint
URI ✅ Required (hex-encoded, max 256 bytes)
Taxon ✅ Required (grouping/category number)
TransferFee ➕ Optional (0–50000 = 0–50% in 0.001% steps)
Flags ➕ Optional (burnable, mutable, transferable, onlyXRP)
NFTokenMinter ➕ Optional (authorized minter address)
🔥 Burn / Modify NFT NFTokenBurn or Metadata Update
NFTokenID ✅ Required (32-byte hex ID)
Owner (for burn) ✅ Must be current holder or issuer (if burnable)
URI (for modify) ➕ New URI (only if tfMutable set at mint)
📝 Important Notes:
  • Requires the NonFungibleTokensV1_1 (or later) amendment to be enabled on the network.
  • Each minted NFT consumes **owner reserve** (~0.2 XRP) from the minter/issuer until burned or transferred (reserve follows current owner).
  • URI: Hex-encoded string (usually pointing to IPFS, Arweave, or HTTPS metadata JSON). Max 256 bytes after encoding. Not validated for content.
  • Taxon: Arbitrary number for grouping NFTs (e.g., collection ID). No uniqueness enforced — same taxon can be used across many NFTs.
  • TransferFee: Royalty-like fee on secondary transfers (0–50%). Only applies if tfTransferable is set and token is sold via NFTokenOffer.
  • Common flags:
    • tfBurnable — Issuer or current holder can burn it
    • tfMutable — URI can be updated post-mint
    • tfTransferable — Can be transferred (default true; disable for soulbound-like)
    • tfOnlyXRP — Can only be offered/sold for XRP
  • Burning requires the current owner (or issuer if burnable) — burns the NFT and frees reserve.
  • Metadata modification (URI change) only possible if tfMutable was set at mint — requires owner to submit NFTokenCreateOffer or similar update mechanism.

⚠️ Irreversibility & Flag Considerations

Many NFT properties are permanent after mint — choose flags and URI carefully.

  • Once minted, most flags (burnable, transferable, onlyXRP, etc.) cannot be changed — they are fixed forever.
  • If tfMutable is **not** set at mint, the URI is **immutable** — you cannot update metadata later.
  • Burning is **permanent** — the NFT ID is destroyed and cannot be recovered or reused.
  • Wrong URI (e.g., broken link, invalid hex) makes the NFT effectively unusable — always test with valid IPFS/Arweave links.
  • Reserve follows the current holder — transferring an NFT moves the reserve cost to the new owner.
  • High TransferFee can discourage trading — values >10% often reduce liquidity.
  • Test mint/burn/update flows on devnet or Testnet first — incorrect flags, URI encoding, or taxon values cause transaction failure and fee burn.
