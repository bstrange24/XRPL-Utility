Account Flags (AccountSet)

AccountSet lets you enable or disable specific account behaviors using SetFlag and ClearFlag.

Requirements

⚙️ Enable Flags
SetFlagRequired
ClearFlagOptional
⚙️ Disable Flags
ClearFlagRequired
SetFlagOptional

📝 Important Notes

  • Use SetFlag to enable or ClearFlag to disable — only one of each per transaction.
  • Check current flags in your AccountRoot via account_info.
  • Some flags are irreversible once enabled (see warnings below).
  • Transaction still costs a fee even if no change occurs.
⚠️ Irreversible & Restricted Flags
  • asfNoFreeze, asfAllowTrustLineClawback, asfAllowTrustLineLocking — irreversible.
  • asfDisableMaster — requires alternative signing method first.
  • asfRequireAuth — only possible with no existing trust lines.
  • Always test on Testnet first.

Deposit Authorization (DepositAuth)

Blocks all incoming payments unless preauthorized. Very useful for compliance and spam protection.

📝 Important Notes

  • Use SetFlag: 9 to enable and ClearFlag: 9 to disable.
  • Once enabled, only preauthorized accounts can send you funds.
  • Preauthorizations cost owner reserve.
}

Multi-Signer (SignerListSet)

Configure multiple keys that can collectively authorize transactions for your account. Useful for shared control, security, and institutional setups.

Requirements

🗝️ Create / Update Signer List
SignerEntries Required (1–8 signers)
Quorum Required
🗑️ Remove Signer List
SignerEntries Empty array
Quorum 0

📝 Important Notes

  • SignerListSet replaces the entire list — you must provide the full desired list.
  • Maximum 8 signers. Each signer has a weight (1–255).
  • Creating/updating a signer list increases your owner reserve.
  • Master key cannot be added as a signer.
⚠️ Security & Lockout Risks
  • If you disable the master key and lose access to enough signers, you may permanently lose control of the account.
  • Always keep access to enough signers to meet the quorum.
  • Test thoroughly on Testnet before mainnet.
}

Modify Regular Key (SetRegularKey)

Assign, change, or remove a secondary key that can sign transactions for your account.

Requirements

🔑 Assign / Change RegularKey
RegularKey Required (address)
🗑️ Remove RegularKey
RegularKey Omit field or empty

📝 Important Notes

  • Use SetRegularKey transaction to assign or remove the regular key.
  • The RegularKey must be a valid XRPL address with known secret.
  • You can use Regular Key for daily transactions while keeping Master Key offline.
⚠️ Security Risks
  • If you disable the master key and lose the regular key, you permanently lose access to the account.
  • Never set RegularKey to an unknown or lost secret.
  • Always test signing with the new key before disabling the master key.
