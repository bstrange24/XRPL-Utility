Trust Lines

Trust Lines allow your account to hold and trade issued currencies (IOUs) from a specific issuer.

Key Operations

🔗 Create / Modify Trust Line
Currency Code Required
Issuer Required
Limit Amount Required
Flags (NoRipple, Freeze, etc.) Optional
❌ Remove Trust Line
Limit Amount = 0 Required
Outstanding Balance Must be 0

📝 Important Notes

  • Trust Lines are required to hold issued tokens (IOUs). XRP does not need one.
  • Setting a positive limit creates a trust line if one does not already exist.
  • To remove a trust line, the balance must be exactly zero and the limit set to 0.
  • Each trust line consumes owner reserve (~0.2 XRP) while active.
  • The issuer can freeze a trust line if they have the Freeze feature enabled.
⚠️ Common Gotchas
  • Reducing the limit does not remove the trust line if balance > 0.
  • Zero-balance trust lines are hidden in this app (normal XRPL behavior).
  • Always test trustline creation/removal on Devnet/Testnet first.
