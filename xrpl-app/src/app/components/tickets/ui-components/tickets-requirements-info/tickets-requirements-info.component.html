XRPL Tickets Overview

Tickets reserve sequence numbers in advance, allowing transactions to be sent out-of-order or in parallel without depending on the account's current Sequence.

🎟️ Ticket Creation Single Transaction
TicketCount ✅ Required
Max per account 250 Tickets
🎟️ Using a Ticket In any Transaction
Sequence ❌ Set to 0
TicketSequence ✅ Required
📝 Important Notes:
  • TicketCount is required in a TicketCreate transaction (1 to 250).
  • Each unused Ticket counts toward your account’s owner reserve (typically 0.2 XRP per Ticket) until used.
  • Tickets allow out-of-order execution — use any available TicketSequence in any order, but each can only be used once.
  • Maximum 250 Tickets per account at any time (creation fails if it would exceed this).

⚠️ Reserve Cost & Cleanup

Tickets reserve XRP until consumed.

  • Each Ticket increases your owner reserve — cost adds up quickly with many Tickets.
  • Once used, the Ticket is removed and the reserve XRP is freed.
  • Unused Tickets remain forever unless the account's Sequence surpasses them (they become invalid but still reserve XRP).
  • Plan TicketCount carefully to avoid locking unnecessary XRP.
