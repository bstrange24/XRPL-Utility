Sending XRP

Direct XRP payments are fast, cheap, and irreversible.

Required / Optional Fields

Destination Required
Amount Required
Destination Tag Optional
Source Tag Optional
Invoice ID Optional
Domain ID Optional
Credential ID Optional

📝 Important Notes

  • Destination and Amount are always required.
  • Use Destination Tag when sending to exchanges (Binance, etc.).
  • Transactions are irreversible — double-check everything.
  • Sending enough XRP to an unfunded address creates a new account.
⚠️ Safety Tips
  • Wrong address or missing tag = permanent loss of funds.
  • Always verify the full recipient address.
  • Consider adding LastLedgerSequence for time-sensitive sends.
