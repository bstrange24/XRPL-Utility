XRPL Multi-Purpose Tokens (MPTs)

Multi-Purpose Tokens are an advanced fungible token standard on the XRPL, with on-chain metadata, supply controls, transfer fees, and compliance features—ideal for real-world asset tokenization and institutional DeFi.

📝 Important Notes:
  • MPTs require the MPTokensV1 amendment to be enabled on the network.
  • Metadata is immutable once set — use on-chain JSON (up to 1024 bytes) or a pointer to off-chain data for details like name, ticker, description (follows XLS-89 schema).
  • Each MPT issuance and each holder's balance counts toward your account’s owner reserve — plan carefully to avoid excessive reserve lockup.
  • Unlike traditional trust lines, MPTs are more efficient and support features like fixed supply caps without blackholing the issuer account.
  • Recipients must authorize holding the MPT (via MPTokenAuthorize) before receiving it.

⚠️ Irreversible & Compliance Considerations

Many MPT properties are permanent after creation.

  • Metadata and most flags cannot be changed post-issuance (future amendments may allow limited mutability).
  • If non-transferable, tokens cannot be moved — useful for credits or locked assets, but irreversible without issuer controls.
  • Supply cap (if set) is hard — you cannot issue beyond MaximumAmount.
  • Deletion of an MPT issuance (MPTokenIssuanceDestroy) is only possible if no holders remain.
